# ALTERAÇÃO PONTUAL — reference_code de 1 a 8 caracteres

Preciso ajustar o contrato e a implementação do campo `reference_code` dos produtos.

## Contexto

Hoje o sistema exige que:

reference_code

tenha exatamente 8 caracteres.

Isso está incorreto para o ERP real.

No ERP, `reference_code` vem de:

tipo.REFERENCIA

e pode ter de 1 até 8 caracteres.

Exemplos válidos:

CPA/1
01CR
12345678
A
AB12

IMPORTANTE:

- O campo deve continuar sendo tratado como TEXTO.
- Nunca converter para número.
- Preservar exatamente o valor vindo do ERP.
- Não completar com zeros.
- Não completar com espaços.
- Não truncar valores válidos.
- O limite máximo continua sendo 8 caracteres.
- O mínimo deve passar a ser 1 caractere.

--------------------------------------------------
1. ALTERAR O OPENAPI
--------------------------------------------------

Localizar todos os schemas e parâmetros relacionados a:

reference_code

Hoje provavelmente estão definidos como:

minLength: 8
maxLength: 8

Alterar para:

minLength: 1
maxLength: 8

Isso deve ser feito tanto no schema de sincronização quanto nos parâmetros de consulta.

Exemplo esperado:

reference_code:
  type: string
  minLength: 1
  maxLength: 8

Garantir que a alteração seja aplicada em:

- sincronização ERP de produtos;

- schemas compartilhados;
- schemas gerados, se aplicável.

3. BACKEND
--------------------------------------------------

reference_code

Não adicionar padding.

Não aplicar padStart.

Não aplicar padEnd.

Não converter para número.

Preservar o valor exatamente como recebido, exceto Trim() se essa já for a política atual dos códigos ERP.

Valores válidos:

"A"

Valores inválidos:
